## 简体中文

一个基于 Swift + SpriteKit 开发的轻量级 macOS 桌面宠物应用。

项目最初的理念是做一个脱离 Web 壳子、纯原生且具备一定 AI 交互能力的桌宠。目前处于早期开发阶段（v0.1.0），部分功能可能仍在完善中。

### ✨ 核心特性

- **纯原生开发**：使用 Swift、AppKit 和 SpriteKit 构建，无任何 Web/Electron 依赖。
- **基础物理引擎**：实现了抛掷、重力下坠、屏幕边缘与天花板碰撞反弹（纯数学计算，未使用物理引擎框架）。
- **像素级点击穿透**：点击宠物透明区域可穿透至下层应用，不阻挡正常办公；点击宠物本体触发互动。
- **兼容 OpenAI 格式的 API**：支持自定义 API 地址、Key 和模型名称（可用于 DeepSeek、OpenAI 或本地 Ollama 等）。
- **TTS 语音支持**：支持系统自带语音，并适配了本地部署的 GPT-SoVITS。
- **可视化命中区域校准**：在设置界面可通过拖拽矩形框，自定义宠物的头、脸、身体、尾巴区域。
- **基础气泡交互**：支持多行文本气泡显示，点击气泡可提前使其消失。

### 📊 性能表现（实测数据）

- **App 体积**：约 23.5 MB（含动画资源）。
- **内存占用**：运行时约 100 MB - 150 MB。
- **CPU 占用**：静止待机时通常在 10% 以下（受渲染帧率和设备性能影响）。

### 📦 安装与运行

1. 前往 Releases 页面下载最新的 `DebuSeek-v0.1.0-macOS.dmg`。
2. 双击打开 `.dmg`，将 `DebuSeek.app` 拖入 `Applications` 文件夹。
3. **⚠️ 首次运行提示**：由于未进行苹果官方公证，系统可能会提示“已损坏”并阻止打开。**不要直接双击 App！**
   **解决方法**：在 `.dmg` 窗口内，双击 **`Fix_Permissions.command`**（修复脚本），输入一次电脑密码，脚本会自动解除安全限制并启动桌宠。之后即可正常双击 App 使用。

### ⚙️ 配置与使用

1. 运行后，右键点击桌宠，选择 **设置**。
2. 在 **聊天** 标签页配置 AI API（目前默认使用 DeepSeek 格式）。
3. 在 **语音** 标签页可配置本地 GPT-SoVITS 服务地址（默认 `http://localhost:9880`）。
4. 配置数据保存在 `~/.DesktopPet/config.json`。

## English

A lightweight native macOS desktop pet application built with Swift & SpriteKit.

The initial idea of this project is to create a desktop pet that breaks away from Web wrappers, is purely native, and possesses basic AI interaction capabilities. Currently in early development (v0.1.0), some features may still be under improvement.

> 🤖 **AI-Native Development**: This project's code was largely generated with the assistance of AI (DeepSeek), serving as an experiment in AI-driven development.

> ⚠️ **Important Note**: The current application UI and the built-in dialogue/behavior systems are **Simplified Chinese only**. Internationalization (i18n) support is planned for future updates.

### ✨ Features

- **100% Native**: Built with Swift, AppKit, and SpriteKit. No Web/Electron overhead.
- **Custom Physics Engine**: Pure math-based throwing, gravity, and collision bouncing (floor, walls, ceiling). No `SKPhysicsBody` used.
- **Pixel-Level Click-Through**: Clicking transparent areas passes events to the underlying app. Only clicking the pet itself triggers interactions.
- **Universal AI API**: Compatible with any OpenAI-formatted API (DeepSeek, OpenAI, Ollama, etc.).
- **TTS Support**: System TTS and local GPT-SoVITS integration.
- **Visual Hit-Zone Calibration**: Adjust the hitboxes (head, face, body, tail) directly in the settings.
- **Dynamic Speech Bubbles**: Multi-line text support; click the bubble to pop/dismiss it.

### 📊 Performance

- **App Size**: ~23.5 MB (including assets).
- **Memory Usage**: ~100 MB - 150 MB.
- **CPU Usage**: Typically < 10% when idle.

### 📦 Installation

1. Download the latest `.dmg` from [Releases](https://github.com/NickeL9740/DebuSeek-mac/releases).
2. Open the `.dmg` and drag `DebuSeek.app` to your `/Applications` folder.
3. **⚠️ First Launch Note**: Since the app is not notarized by Apple, macOS Gatekeeper will block it and falsely claim it's "damaged". **Do not double-click the App directly!**
   **Fix**: Inside the `.dmg` window, double-click **`Fix_Permissions.command`**, enter your Mac password once. The script will automatically bypass the restriction and launch the pet. After that, you can open the App normally.

### ⚙️ Configuration & Usage

1. Right-click the pet and select **Settings**.
2. Go to the **Chat** tab to configure your AI API (OpenAI format).
3. Go to the **TTS** tab to set up the local GPT-SoVITS service (default: `http://localhost:9880`).
4. Configuration data is saved at `~/.DesktopPet/config.json`.
